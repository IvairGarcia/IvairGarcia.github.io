Política de Privacidade

Última atualização: 03 de outubro de 2026

Esta Política explica como o PROVENDAS - Sistema de Gestão Empresarial ("PROVENDAS", "sistema") trata dados pessoais, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD). O PROVENDAS é desenvolvido por Ivair Rodrigues Garcia, Caracol/MS, Brasil ("desenvolvedor"), contato: ivairgarcia100@gmail.com.

1. Como o sistema funciona

O PROVENDAS é instalado no computador servidor da empresa que contrata o sistema ("cliente"). Os dados cadastrados (clientes, produtos, vendas, financeiro, documentos fiscais etc.) ficam gravados no banco de dados local desse computador, sob controle do cliente. O desenvolvedor não tem acesso a esse banco de dados, exceto quando o próprio cliente solicita suporte técnico e autoriza o acesso.

Em relação aos dados dos consumidores e parceiros cadastrados pelo cliente, o cliente é o controlador dos dados, nos termos da LGPD, e responde pela base legal do tratamento (por exemplo, emissão de documentos fiscais, execução de contrato e obrigações legais).

2. Dados tratados pelo sistema

  • Dados cadastrados pelo cliente: dados de seus consumidores, fornecedores, usuários do sistema, produtos, vendas, títulos financeiros e documentos fiscais. Ficam no servidor local do cliente.
  • Dados de licença: razão social, CNPJ e identificação da instalação, usados para validar a licença de uso.
  • Relatórios de erro (opcional): quando ativado pelo cliente, o sistema registra erros técnicos (mensagem do erro, tela, versão do sistema, navegador, nome do usuário do sistema e descrição digitada no "Relatar Problema") e pode enviá-los ao servidor de suporte do desenvolvedor para correção de falhas. Senhas, tokens e certificados não são enviados.
  • Dados da conta Google (opcional): somente se o cliente conectar o Backup no Google Drive — ver item 3.

3. Backup no Google Drive (uso de dados do Google)

O cliente pode, opcionalmente, conectar a conta Google da própria empresa para que o PROVENDAS envie automaticamente cópias de segurança do banco de dados para o Google Drive dessa conta.

Quais dados do Google acessamos:

  • Endereço de e-mail e nome da conta Google (escopos openid e email): exibidos na tela do sistema para o cliente saber qual conta está conectada.
  • Arquivos criados pelo próprio PROVENDAS no Google Drive (escopo https://www.googleapis.com/auth/drive.file): o sistema cria a pasta PROVENDAS Backup, envia os arquivos de backup, lista, baixa (para restauração) e apaga os backups antigos dessa pasta. O sistema não consegue ver, ler, alterar ou apagar nenhum outro arquivo do Google Drive do usuário.
  • Informação de espaço utilizado/disponível no Google Drive, para avisar o cliente quando faltar espaço.

Como usamos: exclusivamente para realizar, listar, restaurar e manter as cópias de segurança solicitadas pelo próprio cliente. Onde ficam: os arquivos de backup ficam somente no Google Drive do cliente; a autorização (token) fica gravada de forma criptografada no servidor local do cliente. O desenvolvedor não recebe, não armazena e não tem acesso aos arquivos de backup, ao token de acesso ou ao conteúdo do Google Drive do cliente.

Não vendemos, não compartilhamos e não transferimos dados obtidos das APIs do Google a terceiros, não os usamos para publicidade e não os usamos para treinar modelos de inteligência artificial.

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google pelo PROVENDAS obedecerão à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O cliente pode, opcionalmente, definir uma senha de criptografia: os arquivos são então criptografados (AES-256) antes do envio e só podem ser abertos com essa senha. Sem senha, o certificado digital, sua senha e o código CSC são retirados da cópia enviada.

Como revogar: a qualquer momento, pelo botão Desconectar no sistema (M6T2 › Backups), que revoga a autorização e apaga o token, ou diretamente na conta Google em myaccount.google.com/permissions. Os arquivos já enviados permanecem no Google Drive do cliente até que ele os apague.

4. Compartilhamento

Os dados não são vendidos nem compartilhados para fins comerciais. Pode haver comunicação de dados com: a Secretaria da Fazenda (SEFAZ), na emissão de documentos fiscais solicitada pelo cliente; o Google, quando o cliente usa o backup no Google Drive; e autoridades públicas, quando exigido por lei ou ordem judicial.

5. Segurança

Adotamos medidas técnicas como: controle de acesso por usuário e grupos de permissão, senhas armazenadas com hash, registro de auditoria de operações sensíveis, tokens e senhas de integração gravados de forma criptografada, comunicação com serviços externos por HTTPS e criptografia opcional dos backups. A segurança física e lógica do computador servidor (antivírus, acesso ao Windows, energia, internet) é de responsabilidade do cliente.

6. Retenção

Os dados permanecem no servidor do cliente enquanto ele utilizar o sistema e conforme as obrigações legais (por exemplo, guarda de documentos fiscais por 5 anos). No Google Drive, o sistema mantém apenas a quantidade de backups configurada pelo cliente (padrão: os 15 mais recentes), apagando automaticamente os mais antigos. Relatórios de erro recebidos pelo desenvolvedor são mantidos pelo tempo necessário à correção e depois descartados.

7. Direitos dos titulares

Os titulares podem solicitar confirmação, acesso, correção, anonimização, portabilidade ou eliminação de seus dados, nos termos do art. 18 da LGPD. Como os dados cadastrais ficam sob controle do cliente (a empresa onde o titular é cliente/fornecedor), o pedido deve ser feito a essa empresa; o desenvolvedor auxilia o cliente no que for necessário. Pedidos relacionados aos dados tratados diretamente pelo desenvolvedor podem ser enviados para ivairgarcia100@gmail.com.

8. Crianças

O PROVENDAS é um sistema de uso empresarial e não se destina a menores de 18 anos.
